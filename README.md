# Spring Demo..JVK



#Hi Hello

A minimal Java 21 Spring Boot web application. It returns a Hello World message at `/hello`.

## Build

From this folder, run:

    mvn clean package

The executable JAR will be created at:

    target/spring-demo-1.0.0.jar

## Run

    java -jar target/spring-demo-1.0.0.jar

Open `http://localhost:8080/hello` in a browser.
